# Security Policy

If you discover a security vulnerability, please report it responsibly so it can be addressed promptly.

Preferred reporting
- Open a private GitHub issue and mark it as a security report (GitHub supports private vulnerability reports), or
- Email the maintainer at the address listed in the repository metadata (or open a private issue if an email is not provided).

What to include
- Clear description of the issue and steps to reproduce.
- Affected versions and environment details.
- Any suggested mitigations or patches (optional).

Response expectations
- The maintainers will acknowledge your report within a few business days and provide an estimated timeline for a fix.
- Do not publicly disclose details until a fix is available or you are given permission.

Disclosure
- After a fix is released, the maintainers may publish a disclosure describing the issue and the remediation steps.
